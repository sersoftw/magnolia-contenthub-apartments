Migración técnica

De Magnolia 6.2 + Java 11 a Magnolia 6.4 + Java 21

El repositorio incluye una guía de migración con riesgos, checklist, pruebas recomendadas y criterios de validación para explicar la transición en entrevista técnica.

  • Fase 1: inventario de módulos, plantillas y dependencias.
  • Fase 2: compatibilidad Java y revisión de código.
  • Fase 3: validación en Magnolia 6.4 / Jakarta EE.
  • Fase 4: pruebas funcionales y plan de rollback.
