# Resumen ejecutivo

## Nombre del proyecto

**Magnolia ContentHub Apartments**

## Objetivo

Crear un proyecto de portfolio orientado a ofertas de empleo que solicitan conocimientos en Magnolia CMS, Java 11, Java 21 y migración entre versiones de plataforma.

## Problema que resuelve

Muchas empresas que usan Magnolia necesitan perfiles capaces de:

- Entender un CMS empresarial.
- Crear componentes editables para usuarios de negocio.
- Separar contenido, presentación y backend.
- Trabajar con Java en entornos legacy y modernos.
- Documentar cambios técnicos y migraciones.

## Solución propuesta

El proyecto simula una plataforma de gestión de contenido para apartamentos turísticos. Magnolia se encarga de la capa editorial y Java se utiliza para representar una API de contenido consumible por canales web o mobile.

## Partes principales

1. **Light module Magnolia**
   - Templates de página.
   - Componentes reutilizables.
   - Diálogos editables.
   - Recursos CSS/JS.
   - Content type conceptual para apartamentos.

2. **API Java 11**
   - Compatible con entornos más tradicionales.
   - Código sencillo, sin dependencias externas.
   - Endpoints JSON para apartamentos.

3. **API Java 21**
   - Modernización del código.
   - Uso de `record`, `List.of`, streams y switch expressions.
   - Código más limpio y cercano a entornos actuales.

4. **Preview estática**
   - Sirve para mostrar visualmente el proyecto en GitHub Pages o portfolio.
   - No depende de tener Magnolia instalado.

5. **Documentación profesional**
   - Instalación.
   - Capturas recomendadas.
   - Migración Magnolia 6.2 + Java 11 a Magnolia 6.4 + Java 21.
   - Texto para portfolio y candidatura.

## Valor para una candidatura

Este proyecto permite decir en una entrevista:

> He analizado los requisitos de la oferta y he creado un proyecto específico para Magnolia, combinando light modules, configuración YAML, plantillas FreeMarker, Java 11, Java 21 y una guía técnica de migración. Aunque mi perfil es junior, he preparado una base práctica y documentada para incorporarme con rapidez a un entorno Magnolia real.
