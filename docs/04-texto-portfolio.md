# Texto para añadir al portfolio

## Título del proyecto

**Magnolia ContentHub Apartments**

## Subtítulo

CMS headless para apartamentos turísticos con Magnolia, Java 11 y Java 21.

## Descripción corta

Proyecto orientado a demostrar conocimientos en Magnolia CMS, Java y arquitectura headless. Incluye un light module con plantillas FreeMarker, componentes editables, diálogos YAML y recursos frontend, además de dos APIs Java independientes: una compatible con Java 11 y otra modernizada con Java 21.

## Descripción profesional

Magnolia ContentHub Apartments es un proyecto de portfolio creado para simular una solución empresarial de gestión de contenido para apartamentos turísticos. El repositorio incluye una estructura de light module para Magnolia CMS, con templates de página, componentes reutilizables, diálogos editables, content type conceptual y recursos CSS/JavaScript. Además, incorpora una API Java 11 y una API Java 21 para demostrar compatibilidad con entornos legacy y modernización tecnológica.

El proyecto se completa con una guía de migración desde Magnolia 6.2 + Java 11 hacia Magnolia 6.4 + Java 21, incluyendo checklist técnico, riesgos, pruebas y plan de rollback.

## Tecnologías

**Magnolia CMS · Java 11 · Java 21 · YAML · FreeMarker · REST · JSON · HTML · CSS · JavaScript · GitHub Actions**

## Puntos fuertes para mostrar

- Light module de Magnolia con estructura profesional.
- Separación entre CMS, API y frontend.
- API Java sin dependencias externas.
- Modernización de Java 11 a Java 21.
- Documentación técnica orientada a una migración real.
- Preview visual apta para GitHub Pages.
